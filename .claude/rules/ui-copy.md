# Words on screen

- **The player is a casually curious motorsport fan**, not technical, who has never seen
  how the model works and doesn't want to.
- Every word on screen (a setting's name and caption, a page intro, a tooltip) says what
  they will see happen, in plain racing words, one short sentence where one will do.
- Leave out mechanics, edge cases and exceptions; those belong in a rule file. When in
  doubt, cut.
- **One name per thing**: *Settings*; the era's overview is *Champions*; *without a drive*;
  *not reached yet* (the run hasn't got there) versus *not available yet* (not built);
  *Pick*, *Start*, *Season*, *Round 3 of 16*; *team* everywhere but the Constructors'
  Championship and its champion. British spelling.
