# alt-hist-race-sim

**Alternate History Racing Simulator** (working name)

An alternate-history motor racing simulator. Starting from the 1980 season, it
simulates race results forward year by year, with drivers ageing, moving between
teams via a transfer market, and retiring — producing a timeline that diverges
from real history.

Status: early development (phase 1, browser-only). Built with TypeScript, React,
and Vite.

See `CLAUDE.md` for architecture and conventions.
